Overview

Thank you for purchasing SmartPOS – All-in-One Point of Sale & Inventory Management System.

SmartPOS is a commercial-grade web application built using Laravel 12, PHP 8.2+, Bootstrap 5, Chart.js, and DataTables. Designed for fast retail POS operations, stock audits, supplier PO receiving, expense tracking, and financial profit reporting.

Server Requirements

Before installing, ensure your web server meets the following system requirements:

  • PHP Version: 8.2 or higher
  • Database: MySQL 5.7+ / MariaDB 10.2+ or SQLite 3.35+
  • PDO PHP Extension
  • OpenSSL PHP Extension
  • Mbstring PHP Extension
  • Tokenizer & XML Extension
  • Ctype & JSON Extension
  • BCMath PHP Extension
  • cURL & GD Extension
  • Mod_Rewrite Enabled (Apache/Nginx)

Step-by-Step Installation

Method A: Web Installer Wizard (Recommended for cPanel)
  1. Upload the files inside Source Code/SmartPOS/ to your web hosting root directory (e.g. public_html/ or subdomain directory).
  2. Configure your web server document root to point to the public/ folder inside the project.
  3. Set file/folder permissions for storage/ and bootstrap/cache/ to 0775 (writable).
  4. Open your browser and navigate to: http://your-domain.com/install
  5. Follow the 6-step interactive wizard:
    • Step 1: Verification of PHP version and required extensions.
    • Step 2: Enter database connection details (Host, Database Name, User, Password).
    • Step 3: Click Run Migrations & Seeders to generate database tables and demo catalog.
    • Step 4: Create Super Administrator account.
    • Step 5: Configure store name, currency symbol, and sales tax rate.
    • Step 6: Installation Complete!
Method B: Local Development Setup (XAMPP / Laragon / Terminal)
# 1. Navigate to project root
cd /path/to/SmartPOS

# 2. Setup Environment
cp .env.example .env
php artisan key:generate

# 3. Migrate and Seed Database
php artisan migrate --seed

# 4. Start Local Server
php artisan serve

Key Features

POS Terminal
Real-time AJAX search by keyword, SKU, or barcode scanner. Live cart calculation, change return, thermal receipt & PDF print.
Automated Inventory
Purchases auto-increment stock. POS checkout auto-decrements stock. Manual stock adjustments with audit log notes.
Multi-Language Support
Instant language switcher between English (🇬🇧) and Bahasa Indonesia (🇮🇩) with session locale persistence.
Financial Reports
Sales, Purchases, Stock Valuation, Best Selling Products, and Net Profit Statement (Net Profit = Revenue - COGS - Expenses).
